ContextFlow 🧠

Shell history that understands your workflows, not just your commands.

View on GitHub

Why ContextFlow?

Every developer has typed history | grep in desperation. You know a command exists somewhere — you just can't find the sequence around it. ContextFlow remembers the workflow, not just the command. It automatically groups commands into workflows when they are executed in the same directory and session.

Features

  • 🔍 Fuzzy search TUI — beautiful Ctrl+R replacement with project context
  • 🧠 Workflow detection — auto-groups related commands by git repo + session
  • 🔁 Replay — step through any past workflow interactively
  • 📤 Export — workflows as .sh scripts or Markdown runbooks
  • 🗑️ Clean — quickly clear your history with cf clean
  • 📊 Stats — most-used commands, busiest repos, session analytics
  • 🔒 Privacy First — 100% local SQLite database. Secrets are automatically redacted.

Interactive TUI

Find what you're looking for instantly with our fast, fuzzy-finding Terminal User Interface.

Installation

go install github.com/Luv-Goel/contextflow/cmd/cf@latest

Setup

Add to your shell config and restart:

# bash — add to ~/.bashrc
eval "$(cf init bash)"

# zsh — add to ~/.zshrc
eval "$(cf init zsh)"

# fish — add to ~/.config/fish/config.fish
cf init fish | source

Command Reference

CommandDescription
